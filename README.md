A newspaper front page that sums up the world's news of Sunday 22 November 2026 in one image: COP31 near a final climate deal, an EU tax on Big Tech, four more killed in Gaza, a cargo ship ablaze in the Baltic, a deadly storm in Brazil, and a 6.7-magnitude quake in Peru, with a ticker of the day's other big stories. The image is drawn with Python and PIL in `build_image.py`; `main.ts` copies the finished `entry.png` to the output.

## Run

```sh
python3 build_image.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
